# ai-settings

Мои настройки для AI-харнессов: глобальные правила, скиллы и агенты, которые один установщик раскладывает по харнессам и проектам.

## Language

**Харнесс**:
Программа, в которой работает агент-ассистент: Claude Code, OpenCode, Codex CLI, Gemini CLI, Cursor.
_Avoid_: клиент, IDE, тул

**Агент**:
Субагент с отдельным контекстом, своим промптом и набором инструментов, которому главный агент отдаёт задачу целиком.
_Avoid_: субагент, бот

**Шаблон агента**:
Описание агента в этой репе, из которого собираются глобальный и проектный агенты; вместо конкретной модели в нём уровень модели.
_Avoid_: исходник агента

**Глобальный агент**:
Агент из шаблона, установленный для всех проектов харнесса и работающий на модели сессии.
_Avoid_: user agent, дефолтный агент

**Уровень модели**:
Класс модели, который шаблон агента требует вместо конкретной модели: `frontier` или `standard`.
_Avoid_: алиас (в Claude Code алиасы — это `opus`, `sonnet`), tier, low/medium (это уровни effort)

**Проектный агент**:
Агент, собранный из шаблона внутри одного проекта с конкретными моделями под его уровни; перекрывает одноимённого глобального агента и в git проекта не попадает.
_Avoid_: локальный агент, per-project agent
