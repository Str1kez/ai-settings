# ADR 0003: уровень модели fast

Статус: принято (2026-11-08). Дополняет [ADR 0002](0002-project-agents.md): меняет пункт 2 «Решения» про модель глобального агента и добавляет третий уровень.

## Контекст

ADR 0002 даёт два уровня, `frontier` и `standard`, и глобальный агент на любом из них идёт на модели сессии. Для ревью и кодинга этого хватает. Для дешёвой механики не хватает: прогнать dry-run, применить план, снять статус хоста. Работа не требует рассуждений, но на модели сессии она стоит как рассуждения.

В lite-llm-vpn я напоминал оркестратору «запусти на haiku» четыре раза. 15 операторов получили брифы, написанные с нуля, от 0.5 до 6.6k символов. Модель по умолчанию должна лежать в определении агента, а не в моей памяти.

## Решение

1. Третий уровень `fast` в `MODEL_LEVELS`. Это дешёвая модель для механической работы по готовому брифу.
2. Глобальный агент Claude Code на `fast` получает `model: haiku`. Это отступление от ADR 0002: модель сессии для такой работы неправильный дефолт, потому что она может быть самой дорогой из доступных. `frontier` и `standard` по-прежнему наследуют модель сессии (`model: inherit`).
3. Глобальный агент OpenCode остаётся без `model` на всех уровнях, `fast` тоже. Общего id дешёвой модели у провайдеров нет, а выдумывать его я не буду. Глобальный `operator` в OpenCode поэтому едет на модели сессии и дешёвым не будет, пока проект не задаст модель.
4. Проектный агент берёт модель уровня из флагов: `--claude-models` и `--opencode-models`. Для `fast` в Claude Code дефолт при вопросе — `haiku`, у OpenCode дефолта нет, как и у других уровней.
5. Первый агент на этом уровне — `operator`: `fast`, `effort: low`, инструменты `Read, Grep, Glob, Bash`. Он выполняет команды из брифа и отчитывается дословно.

## Последствия

- Проектный запуск `init-project.sh` теперь требует модель и для `fast`. Повторный запуск в проекте со старыми агентами остановится с `missing-model: <харнесс> fast` и попросит флаг.
- В OpenCode дешёвая механика без `--opencode-models` идёт на модели сессии. Это цена того, что я не знаю общий id дешёвой модели.
- Правка шаблона доходит до глобальных агентов только после `install.sh`, как и раньше.

## Отклонённые варианты

- **Просить оркестратора указывать модель в каждом вызове.** Так и было, и я напоминал это четыре раза. Забытая подсказка молча стоит денег.
- **Конкретный id дешёвой модели в глобальном агенте OpenCode.** Он зависит от провайдера, и в половине случаев агент не запустится.
- **Отдельное поле `cheap: true` вместо уровня.** Второй механизм рядом с `model`, а уровни и их привязка к моделям уже есть.
