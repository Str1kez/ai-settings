# Changelog

## [1.3.0] — 2026-10-03

### Изменено

- Phase 2 больше не вызывает `brainstorming` из Superpowers: контекст, вопросы по одному, 2–3 направления с рекомендацией, выбор пользователя и `brainstorm.md` пайплайн теперь проводит сам. Внешней зависимостью остался только `grilling`.

## [1.2.0] — 2026-07-20

### Добавлено

- Обязательный анализ пустого или существующего проекта до brainstorming.
- Выбор исследований с отдельным свежим агентом на каждый выбранный трек и синтезом результатов перед grilling.

## [1.1.0] — 2026-07-20

### Изменено

- Pipeline начинает работу с выбора направления через embedded-режим оригинального `brainstorming`, а затем передаёт выбранный вариант в `grilling`.

## [1.0.0] — 2026-07-20

### Добавлено

- Адаптивный pipeline продуктовой спецификации для идей, улучшений и небольших задач.
- Интерактивный grilling, межмодельная проверка и 2 независимых ревью через Orca orchestration.
- Шаблон спецификации и рубрика ревью для задач разного масштаба.
