## [1.2.0] — 2026-10-04
### Изменено
- Записи снова на русском, с заголовками Добавлено / Исправлено / Удалено / Изменено: CHANGELOG я веду на русском. Если файл уже ведётся на другом языке, скилл продолжает на нём, чтобы не смешивать языки.

## [1.1.0] — 2026-08-09
### Изменено
- Шаблоны секций (Process) переведены на английский: Added/Fixed/Removed/Changed вместо Добавлено/Исправлено/Удалено/Изменено — вывод скилла теперь на английском.

## [1.0.0] — 2026-04-18

### Первый релиз
- Добавление записи в корневой `CHANGELOG.md` по формату Keep a Changelog.
- Автоматический выбор секции (`Добавлено` / `Исправлено` / `Удалено` / `Изменено`) по типу коммита.
- Запись только в `[Unreleased]`, релизные версии не трогаются.
