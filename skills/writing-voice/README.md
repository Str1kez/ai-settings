# writing-voice

Скилл задаёт голос текстов, которые уходят людям от моего имени: описание PR, записи в CHANGELOG и TODO, доки, README, ADR, спеки, посты и статьи. Прямой тон от первого лица, факт отдельно от мнения, стоп-лист канцелярита и инфобиза, кавычки только для прямых цитат, без эмодзи.

## Когда вызывается

- Агент пишет текст, который прочитают люди: CHANGELOG, PR, док, пост.
- Другие скиллы (`ru-pr-description`, `changelog-entry`) отсылают к нему за тоном.

## Когда пропускается

Коммиты (они на английском, за них отвечает `en-commit-message`), UI-строки, ошибки для конечных пользователей, комментарии в коде, API-доки, юридические тексты, ответы в чате (для них есть `docs/ai/style.md`).

## Пример

Запрос: «допиши в CHANGELOG, что `ship` теперь работает без remote».

Без скилла: «Улучшена работа скилла ship в репозиториях без удалённого репозитория».

Со скиллом: «Скилл `ship` пропускает push и PR, если у репозитория нет remote, и вливает ветку в базовую локально. Раньше он падал на `git push`».
