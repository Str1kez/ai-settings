# ship

Скилл доводит готовую ветку до main: проверки, CHANGELOG, коммит, PR, мёрдж, чистка локальной ветки. Агент вызывает его сам, когда ты просишь довести работу до конца. Руками его запускать не нужно.

## Когда вызывается

- «доведи ветку», «оформи PR», «смёрджи», «закрой задачу».

## Когда пропускается

- Просят только текст коммита или PR.
- Нет git-репозитория.
- Реализация ещё идёт.

## Как работает

Глубину задаёт запрос. «Оформи PR» останавливается после создания PR. «Смёрджи» и «доведи ветку» идут до мёрджа и чистки.

Пример: после «доведи ветку» агент прогоняет `make lint test`, добавляет запись в `CHANGELOG.md`, коммитит, открывает PR и мёрджит через squash. В отчёте остаются ссылка на PR, статус `MERGED` и список пропущенных шагов.

## Что не трогает

- Remote-ветка остаётся на origin, удаляется только локальная.
- Теги и версии включаются, только если они уже есть в репозитории: есть теги и версионные заголовки в `CHANGELOG.md`. Тогда агент следует релизному процессу репозитория. В остальных репозиториях этот шаг пропускается.
- Красные проверки останавливают скилл: он показывает вывод и ничего не мёрджит.
