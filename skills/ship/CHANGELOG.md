# CHANGELOG — ship

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), семантическое версионирование.

## [1.1.0] — 2026-11-06

### Изменено
- База ветки определяется по разделу git в `AGENTS.md` репозитория, затем по `origin/HEAD`, затем по `main` или `master`. Раньше везде стояла `main`.
- В репозитории без remote шаги push и PR пропускаются, ветка вливается в базовую локально способом из `AGENTS.md`, а если там пусто, скилл один раз спрашивает. `git pull` в чистке идёт только при наличии remote.

## [1.0.0] — 2026-11-05

### Первый релиз
- Агент сам доводит готовую ветку до main: проверки, запись в CHANGELOG, коммит, PR, squash-мёрдж, удаление локальной ветки. Глубину задаёт запрос: «оформи PR» останавливается на PR, «смёрджи» идёт до чистки.
- Remote-ветка остаётся на origin.
- Теги и версии включаются, только если в репозитории они уже есть.
