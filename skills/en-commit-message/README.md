# en-commit-message

Generates a conventional-commit message in English from `git diff --staged`.

## When it's invoked

- Explicitly: "write a commit", "generate a commit message", "describe this diff for a commit".
- Automatically: before `git commit` without `-m`.

## When it's skipped

- The user already wrote a message.
- Merge or revert commits (auto-generated by git).

## Usage

After `git add`:

1. Tell Claude: "write a commit".
2. It reads `git diff --staged` and produces a ready-to-use message.
3. Paste it into `git commit -m "..."` or let Claude commit directly (with confirmation).

## Example

```
feat(auth): add GitHub OAuth login

Closes #42. Regular login/password stays as a fallback in case the
OAuth provider is unavailable.
```

More examples by change type in `references/examples.md`.
